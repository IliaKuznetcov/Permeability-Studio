# Changelog

## v1.0.0 — first public source release (2026-10-29)

- Established the first public release version from the internally developed 4.5.2 codebase.
- Included the PySide6 desktop application, pulse selection, check-plug volume calibration, late-time permeability analysis, explicit/adaptive-BDF FDM history matching, porosity analysis, and Klinkenberg regression.
- Included the original desktop icon and Windows packaging script.
- Reduced the public documentation to user-oriented and technical guides.
- Excluded real experimental sessions, machine-specific paths, generated bytecode, build outputs, and stale packaging specifications.
- Standardized the displayed application version to 1.0.0 without changing scientific algorithms or session schema versions.

Earlier internal development notes are retained in the original development archive rather than this public package.

### Public example sessions

- Included anonymized recorded shale pulse-decay and check-plug calibration sessions under `examples/`.
