# Changelog

## v1.0.0 — Initial public release (2026-10-29)

- PySide6 desktop application for gas pulse-decay measurements and analysis.
- Interactive pressure/temperature pulse selection and check-plug volume calibration.
- Explicit and adaptive-BDF finite-difference history matching, late-time methods, porosity and Klinkenberg analysis.
- Anonymized shale pulse-decay and check-plug example sessions.
- Documentation, Windows build script, and application icons.
